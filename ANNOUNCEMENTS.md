## ⚠️ Critical Reminders (read first)

- **IBM Bob IDE is mandatory** for all submissions — judges evaluate based on the
  exported Bob session reports.
- **Bobcoins (a.k.a. BP Coins): 40 per team member.** Manage usage carefully —
  if you run out, you may not be able to export your work.
- **GitHub repo must be public.** Private repos cannot be reviewed.
- **Exported Bob task session reports are required** in the repo under a
  `bob_sessions/` directory.
- **Never expose API keys** in the repo — IBM security scanners run 24/7 and will
  immediately deactivate cloud access if a key is found.
- **Getting help:** post in the support channel and tag the mentor roles. Do not
  DM mentors — posting in the channel is the fastest way to a response.
