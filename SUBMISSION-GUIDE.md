# lablab.ai Hackathon — Process & Submission Guide

> Working notes on the general lablab.ai hackathon flow, from registration to
> final submission. Part of the temporary `prepare` branch.
> Source: https://lablab.ai/ai-articles/hackathon-guidelines

## Hackathon Process — 5 Steps

1. Complete your lablab.ai profile
2. Register for the hackathon
3. Connect your Discord account
4. Create or join a team
5. Submit your project

## 1. Signing Up

- Go to the hackathon page on lablab.ai and click the green **"Enrol Now"**
  button (bottom of the page / main event page).
- If you don't have an account, you're prompted to sign up and create a
  participant profile first.

## 2. Forming a Team

Connect your Discord account to your lablab.ai profile first (required for team
collaboration). Then on the hackathon page click **"Create or Join a team"**.

- **Create a team:** select "Create a team", fill in team details, then invite
  teammates or let others request to join.
- **Join a team:**
  - Browse teams on the hackathon page with a *"looking for members"* badge —
    open their dashboard and use chat to check for a fit.
  - Or use the hackathon's Discord server, `#looking-for-team` channel.

> Solo participation is also allowed for the IBM Bob Hackathon.

## 3. Submitting the Project

Scroll down the hackathon page and click **"Submit project"**. A multi-step form
follows.

### Step 1 — Project Information

| Field              | Requirement                                              |
|--------------------|----------------------------------------------------------|
| Submission Title   | Concise title — **max 50 characters**                    |
| Short Description  | Brief summary — **max 255 characters**                   |
| Long Description   | Full explanation of the idea — **min 100 words**         |
| Main Tracks        | Primary categories (listed on the hackathon page)        |
| Technologies       | All technologies used (see lablab.ai/tech)               |

### Step 2 — Media Uploads

| Field              | Requirement                                              |
|--------------------|----------------------------------------------------------|
| Cover Image        | Visually appealing — recommended **16:9 ratio**          |
| Video Presentation | Link — **under 300MB**, **max 5 minutes**                |

### Step 3 — Technical Details

| Field                     | Requirement                                       |
|---------------------------|---------------------------------------------------|
| GitHub Repository         | Public repo link; list extra repos in README.md   |
| Demo Application Platform | Platform where the app is deployed                |
| Demo Application URL      | Direct URL to the live demo                       |
| Additional Information    | Other notes for judges (e.g. how it could scale)  |

Click **"Submit"** to finalize.

## IBM Bob Hackathon — Extra Requirements

Beyond the standard form, this hackathon also requires (see `HACKATHON.md`):

- A **slide presentation** in addition to the video
- The **exported IBM Bob report** of all relevant tasks/sessions, included in
  the public GitHub repository
- A submission that **clearly demonstrates meaningful use of IBM Bob** —
  otherwise it may be disqualified

## Submission Field Cheat Sheet

- [ ] Title ≤ 50 characters
- [ ] Short description ≤ 255 characters
- [ ] Long description ≥ 100 words
- [ ] Cover image, 16:9
- [ ] Video ≤ 5 min and ≤ 300MB
- [ ] Slide presentation prepared
- [ ] Public GitHub repo with exported IBM Bob report
- [ ] Demo platform + live demo URL ready
- [ ] Main tracks and technologies tagged

## FAQ Notes

- **Beginner-friendly:** many lablab.ai hackathons welcome beginners and provide
  learning resources, mentor support, and clear submission guidelines.
- **Cost:** most online lablab.ai hackathons are free to join.
- **Project ideas:** strongest projects solve real problems quickly — agents,
  chatbots, recommendation systems, or generative AI apps in areas like
  education, healthcare, finance, or productivity.
