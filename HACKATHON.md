## The Challenge — "Turn idea into impact faster"

Build a proof-of-concept solution using **IBM Bob** that speeds up everyday
development work. Possible directions:

- Get up to speed on existing code quickly
- Generate documentation and tests
- Reduce effort spent on repetitive tasks that slow a team down

Show how a solution powered by Bob helps builders at any skill level deliver
high-quality software with greater efficiency and confidence.

> **Critical rule:** Every submission must clearly demonstrate meaningful use of
> IBM Bob. Projects that do not show meaningful use of Bob may be disqualified.

## About IBM Bob

IBM Bob is an AI-powered development partner that works directly with a codebase
with full repository context. It:

- Understands developer intent
- Reads complete repository context
- Explains logic with clarity
- Automates complex transformations
- Streamlines multi-step work

Access is provided only for the duration of the event, usage is limited and
should be managed throughout the build, and participants are expected to
actively use Bob as part of their solution. Activate via the official IBM Bob
Setup Guide linked on the hackathon page.
